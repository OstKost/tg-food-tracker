# ADR-0002: Google Sheets as storage

- Status: Accepted
- Date: 2026-09-14

## Context

Приложение предназначено для одного владельца, а история должна быть видна и доступна
для ручной проверки без отдельной админ-панели.

## Decision

Google Sheets — единственное постоянное хранилище. Используются Meals, Dashboard и
ReportLog. Стабильные IDs лежат в колонках; номера строк не являются идентификаторами.
Один процесс сериализует check/append и find/update операции.

## Consequences

БД, ORM, миграции и очередь исключены. Идемпотентность реализуется `event_key` и
повторным чтением после неизвестного результата append. Между Sheets и Telegram нет
общей транзакции, поэтому дневной отчёт имеет at-most-once семантику.

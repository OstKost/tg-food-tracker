# ADR-0004: Optional Gemini food-analysis provider

- Status: Accepted
- Date: 2026-09-14

## Context

Личному дневнику нужен резервный выбор AI-провайдера без изменения остального приложения
и без дублирования одной записи еды в двух внешних сервисах.

## Decision

Добавить Gemini Interactions API как альтернативный адаптер `FoodAnalyzer`. Выбор задаётся
`AI_PROVIDER=openai|gemini`; OpenAI остаётся значением по умолчанию. Gemini использует
`GEMINI_API_KEY`, `GEMINI_MODEL` и JSON Schema в `response_format`.

За один запрос выбирается только один провайдер. Автоматический fallback запрещён: он
создал бы лишнюю стоимость, утечку текста во второй сервис и неоднозначность результата.
Оба адаптера получают один контракт и проходят одинаковую Pydantic-валидацию.

## Consequences

Настройка требует ключа только выбранного провайдера. Переход на Gemini не меняет Google
Sheets, Telegram, идемпотентность или хранение. Модель и тарифы должны проверяться перед
живым запуском в Google AI Studio.

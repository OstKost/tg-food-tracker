# ADR-0003: OpenAI food analysis

- Status: Accepted
- Date: 2026-09-14

## Context

Свободный русский текст нужно превратить в приблизительные блюда, порции и КБЖУ без
собственного продуктового справочника.

## Decision

Первый адаптер использует OpenAI Responses API, версионированную JSON Schema и
`store=false`. Модель задаётся `OPENAI_MODEL`; начальное значение —
`gpt-5.4-mini-2026-03-17`. Месячный бюджет пилота — 20 USD.

## Consequences

Оценки приблизительны. Pydantic повторно проверяет ответ, приложение пересчитывает
итоги из позиций и просит подтверждение для 5 001–10 000 kcal. Gemini добавлен
отдельным решением в ADR-0004; продуктовый справочник требует нового решения.
